## 基本信息
- **功能名称**: 老仓育（公式弹道主 C + 压力传导被动）
- **所属模块**: Chess / Skill / Bullet / Buff（压力系统）
- **需求类型**: 新增功能
- **优先级**: P0
- **预估复杂度**: L2（新弹道移动 + 被动 + 主动技能 + Prefab/Asset）
- **预估耗时**: 8–12 小时
- **提出日期**: 2026-07-09
- **定稿日期**: 2026-07-09

## 功能描述

### 详细描述

**老仓育**为物语篇主 C 植物：以**一颗常驻弹道点**为攻击载体，沿参数方程轨迹循环运动，中心始终锚定在**老仓所在格**；触碰敌方造成伤害。

**轨迹方程（李萨如形式）**：

```text
x = A · sin(a·t + φ)
y = B · sin(b·t)
中心 = 老仓当前格世界坐标（随老仓移动）
ω = k · 老仓当前攻速（实时）
```

#### 参数来源与更新时机

| 参数 | 含义 | 来源 | 更新时机 |
|------|------|------|----------|
| **A** | 横向振幅（格） | 老仓**所在行**友方数量（**含老仓**） | 种下时、**主动技能**使用时快照 |
| **B** | 纵向振幅（格） | 老仓**所在列**友方数量（**含老仓**） | 同上 |
| **ω** | 角速度 | `ωScale × 当前攻速`（ωScale 默认 1，可配置） | **每帧/实时** |
| **a:b** | 轨迹形状（圆/椭圆/8 字等） | 由**老仓当前压力值**按公式拆分（见下） | 种下默认 1:1；**主动技能**使用时重算 |
| **φ** | 初相位 | 配置默认 0 | 种下 / 技能（可选，默认不变） |

**快照规则**：
- 种下后仅老仓一人 → **A=1, B=1, a:b=1:1**。
- 之后在同行/同列补种其他植物 → **A、B、a:b 不变**（不实时统计）。
- 玩家**点击主动技能** → 按**当前**行列友方数重算 A、B，并按**当前压力**重算 a:b。
- **主动技能与压力增减无关**：不消耗、不增加压力。

**A / B 上限（建议）**：`clamp(友方数, 1, maxAmplitude)`，`maxAmplitude` 默认 5–9，策划可配。

#### a:b ← 压力值（主动技能时）

种下时 **a:b = 1:1**。每次主动技能使用时，读取老仓 `context["stress"]`，按下式得到整数比：

```text
a : b = stress : 30
```

实现时取**最简整数比**（两边同除以 `gcd(stress, 30)`），再对 a、b 各自 clamp 至 `[1, ratioMax]`（ratioMax 默认 9，防极端形状）。

**示例**：

| 压力 | 原始比 | 最简 a:b |
|------|--------|----------|
| 30 | 30:30 | **1:1** |
| 45 | 45:30 | **3:2** |
| 60 | 60:30 | **2:1** |
| 90 | 90:30 | **3:1** |
| 32 | 32:30 | **16:15** |

与被动「压力下限 30」一致：压力不低于 30 时，**a:b 最低为 1:1**。

#### 被动：压力传导 + 压力下限

1. **压力来源**：完全由**外部**给予（课本、Tomo 矫正、关卡机制等）；老仓**不能**自行调控压力（无自增/自减技能）。
2. **压力下限**：老仓自身压力值**不得低于 30**（任何减少压力的 Buff/效果对老仓生效后，`stress = max(stress, 30)`）。
3. **传导触发**：当老仓压力**增加** Δ（`newStress > oldStress`）时，对**八邻格**内单位施加 **+Δ** 压力。
4. **八邻格范围**：以老仓所在格为中心的 3×3 **去掉中心**，共 **8 格**；**不含老仓自己**。
5. **目标**：八邻格内**所有单位**（友方 + 敌方）；每个格子上 `tile` 上的 Chess 均可成为目标。
6. **无压力 Buff**：与 **Tomo** 一致——目标若无「压力」Buff，先 `AddBuff(Buff_StressBuff_Death)`，再 `BuffReset(extraStress = Δ)`。
7. **不递归、不连锁**：
   - 传导**不会**再作用到老仓本人；
   - 仅老仓被动触发**一层**扩散，接收者压力上升**不会**因本被动再次向外传递（避免循环）。

#### 伤害

- 常驻弹道触碰敌方 → 造成老仓攻击力伤害（走现有 `DamageMessege`）。
- 同一敌方 **触碰 CD** 建议 0.2–0.5s（可配置），防贴脸秒杀。
- 判定：弹道世界坐标 + `hitRadius`（默认约半格）与敌方碰撞/格点检测（实现期二选一，与现有 Bullet 体系对齐）。

### 用户故事

作为玩家，我希望老仓育用一颗沿数学曲线扫射的常驻弹道打主 C 输出；通过主动技能在「铺好行列」后刷新打击范围（A/B），并用当前压力「推导」出轨迹形状（a:b）；同时老仓会把所承受的压力波动传导给周围八格的所有单位，形成阵列/学校关的压力联动。

### 需求类型判定理由

老仓育 Prefab/Asset 为空壳，属**全新棋子机制**：新弹道移动 + 新被动 + 新主动，与现有压力系统**集成**但不修改压力全局规则。

### 集成点

- **调用**：
  - `MapManage` / `Tile` — 行列统计、八邻格枚举
  - `skillController.context` — `TryGet/Set<int>("stress")`、`OnValueChange`
  - `Buff_StressBuff_Death.BuffReset` — 传导与下限
  - `propertyController.GetAttack()`、`GetAttackSpeed()` — 伤害与 ω
  - `Bullet` 生成/常驻 — 与老仓生命周期绑定
- **触发**：
  - 老仓 `WhenEnterGame` — 生成常驻弹、初始 A/B/a:b
  - 主动技能 — 快照 A/B/a:b
  - `OnValueChange` — 压力增加 → 八邻格传导
- **新增**（建议）：
  - `BulletMove_Lissajous`（或扩展 `BulletMoveCurve`）— 参数方程移动
  - `Passive_Okuwaki_StressSpread` — 压力传导 + 下限 30
  - `SkillEffect_Okuwaki_RefreshCurve` — 主动刷新 A/B/a:b
  - `OkuwakiCurveHelper` — 行列计数、八邻格、压力→a:b 拆分

### 对现有功能的影响

- **接口变更**：无破坏性；新增 Helper 可选
- **行为变更**：无；老仓被动仅作用于老仓自身上下文与八邻格
- **数据变更**：`老仓育.prefab`、`老仓育.asset` 补全武器/技能/Buff 配置

## 参数合法域

| 参数 | 合法范围 | 非法/退化处理 |
|------|----------|----------------|
| A, B | ≥ 1，≤ maxAmplitude | 友方数 0 时按 1 计（老仓总在） |
| a, b | 整数 ≥ 1，≤ ratioMax | b=0 → 1 |
| ω | > 0 | ≤ ωMax，防漏判 |
| stress（老仓） | ≥ **30**（被动下限） | 减少后 clamp |
| touchCd | ≥ 0.2s | — |

## 技术要求

- **Unity 版本**: 与项目一致
- **依赖模块**: Chess, Skill, Bullet, Buff, Map
- **架构约束**: `ISkillEffect` + Chess 事件；**禁止**技能专用运行时 MonoBehaviour（见项目规则）
- **性能要求**: 单颗常驻弹；八邻格传导 O(8×格内棋子数)；不每帧重算 A/B
- **兼容性**: 与 GBC/学校关压力机制共存；传导可作用于僵尸

## 验收标准

- [ ] 种下老仓：A=1,B=1,a:b=1:1，弹道绕中心循环
- [ ] 同行/同列补种后不点技能：A/B 仍为 1
- [ ] 点主动技能：A/B 等于当前行列友方数（含自己）；a:b = stress:30 最简比（如 P=45 → 3:2，P=60 → 2:1）
- [ ] 攻速变化时 ω 同步变化；A/B/a:b 不随攻速变
- [ ] 老仓压力 +5：八邻格内各单位 +5（无 Buff 先挂）；老仓本人不二次吃传导
- [ ] 老仓压力试图降到 29：clamp 为 30
- [ ] 邻格单位因传导获得压力：**不会**触发老仓被动再次向外传
- [ ] 传导可作用于敌方僵尸（若该格有僵尸）
