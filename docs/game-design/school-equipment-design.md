## 1. 设计定位

与 **舞台器具**（Live / 演出）并列，**学校道具** 面向走廊、教室、小卖部、章鱼噼篇等校园内容。复用同一套 **PlantType 壳**：

| 壳子 | 本批学校道具 |
|------|----------------|
| `MainPlant` | **自动贩卖机** |
| `SupportPlant` | **文具盒** |
| `Consume` + `ConsumePlant` | **课本**；**章鱼噼**（已实现） |

**主题标签**（建议）：`学校道具`（便于学校关 / 章鱼噼篇进池筛选）

**与舞台器具关系**：机制独立、可共用脚本模式（Support 套 Main、Consume 一次性）；**不强制**与 `舞台器具` tag 互斥。

## 2. 自动贩卖机（Vending Machine）

### 2.1 玩家理解

「小卖部机器——花阳光摇一下，随机掉 **食物类卡牌**。」

### 2.2 种植规则

- `PlantType`: **MainPlant**
- `IPlantFunction`: **MainPlant**（独占草地格）
- `chessTileType`: **Grass**（学校关可配专用背景，规则不变）
- **不可**与同格其他 Main 共存；可挂 **1 个 Support**（如文具盒，若种在同一 Main 上则指其他格的 Support——贩卖机自己是 Main，Support 应种在别格射手上）

### 2.3 核心机制

**定位**：偏 **经济 + 阻挡**，类似 **坚果 + 生产** 混合体（非向日葵式自动产阳，而是 **主动消费摇奖**）。

| 参数 | 方向（待定） | 说明 |
|------|--------------|------|
| HP | **坚果档** | 参考波奇 **4000** 或南瓜 **4000**；具体后定 |
| 单次摇奖费用 | **25 阳光** | 用户指定；阳光不足时不可摇 |
| 交互方式 | **点击已种植的贩卖机** | 扣 25 阳 → 从奖池随机 1 张 **食物类卡牌** |
| 产出形态 | **加入本关手牌 / 种子包**（待定） | 与 `PlantsShop`、选卡流程对齐，实现时再定 |

**奖池（食物类 Consume，可扩展）**：

| 卡牌 | 现有档位 | 备注 |
|------|----------|------|
| 甜甜圈 | 25 | 已在构筑表 |
| 蛋包饭 | 25 | 已在构筑表 |
| 抹茶芭菲 | 75 | 已在构筑表 |
| 牛肉饭 | 75 | 已在构筑表 |
| 红茶 | — | **策划预留**；Asset 未建则先不进池 |

权重、是否按费用分 tier、能否摇出已拥有上限等 → **§8 待确认**。

### 2.4 数值与池子（待定）

| 字段 | 建议 |
|------|------|
| 种植费用 | **50～75**（经济 plant，低于输出、高于纯消耗品） |
| HP | **3000～4000** |
| 进池 | 学校关 / 章鱼噼篇 / 通用（后定） |

### 2.5 实现要点（后续）

- 主动技能或 **点击交互** + `SunLightPanel.instance.ChangeSunLight(-25)` 校验
- 随机：`PropertyCreator` 列表或 `ScriptableObject` 奖池表
- 发牌：调用与商店/奖励一致的 **加牌入 hand** API（需对照 `PlantsShop` / `PreParePlugun_ShowPlantShop`）
- **非**每帧产阳，避免与 486 / 桃金娘重复

### 2.6 演出

- 待机：玻璃柜闪光
- 摇奖：出货动画 + 卡牌图标飞向手牌栏

## 3. 文具盒（Stationery Box）

### 3.1 玩家理解

「攻击时从盒子里甩 random 文具当子弹。」

### 3.2 种植规则

- `PlantType`: **SupportPlant**
- `IPlantFunction`: **SupportPlantRequireMain**（必须种在已有 Main 的格上）
- 同格 **1 个 Support**（与南瓜罩 / 舞台麦克风 / 聚光灯互斥）
- **不替 Main 承伤**（默认，与舞台麦克风一致）

### 3.3 核心机制

**触发**：同格 **宿主 Main** 每次 **普攻**（`equipWeapon.OnAttack`）时，额外发射 **1 发随机文具弹**。

| 参数 | 方向（待定） | 说明 |
|------|--------------|------|
| 文具种类 | 配置表随机 | 例：铅笔、橡皮、尺子、圆规、墨水瓶（仅 VFX/伤害倍率区分） |
| 伤害 | 宿主攻击力 × 系数 | 或固定面板；后定 |
| 弹道 | 与宿主默认射击方向一致 | 复用 `Bullet` + `ObjectPool` |
| 与宿主子弹关系 | **额外 1 发** | 不替换原攻击 |

**参考实现**：`Buff_Vocal.OnAttack` 额外 `InitBullet` 模式；改为随机 `GameObject` bullet prefab 列表。

### 3.4 数值与池子（待定）

| 字段 | 建议 |
|------|------|
| 种植费用 | **125**（Support 档，对齐南瓜罩） |
| HP | **3000～4000** |
| 进池 | 学校关优先 |

### 3.5 演出

- 每种文具不同拖尾/命中特效（可第一版共用 1 弹 + 随机 Sprite）

## 4. 课本（Textbook）— 消耗品

### 4.1 玩家理解

「把课本压给（右方）同学——对方压力↑，你拿到阳光。」（风险/经济交换）

### 4.2 种植规则

- `PlantType`: **Consume**
- `IPlantFunction`: **ConsumePlant**（仅 `tile.stander != null`）
- `activeSkill`: **ConsumablesSkill**（入场 `UseSkill` → 效果 → `SkillOver` → `Death()`）

### 4.3 核心机制（用户原意 + 待澄清）

**用户描述**：种在 Main 上 → **右方角色获得压力值**，**同时获得阳光**。

**文档暂记解读**（实现前须拍板 §8 #1）：

```text
1. 消耗课本（种在宿主 Main 格上）
2. 玩家阳光 +sunGain（待定，如 50～75）
3. 「右方角色」获得压力 +stressGain（待定）
   - 暂默认：宿主所在格 **右侧相邻格** 的友方 Main（tile.stander）
   - 若该格无 Main / 为敌 → 仅玩家得阳或效果部分失效（待定）
4. 压力接入现有 Buff_StressBuff_Death / context["stress"]（与 GBC、章鱼噼篇一致）
5. ConsumablesSkill.SkillOver → 课本 Death()
```

**与章鱼噼对比**：

| | 课本 | 章鱼噼 |
|---|------|--------|
| 压力 | **施加**给右方友军 | **消耗**宿主压力换击杀 |
| 阳光 | 玩家 **获得** | 无 |
| 章节 | 学校通用 | 章鱼噼篇 P0 **已实现** |

### 4.4 数值与池子（待定）

| 字段 | 建议 |
|------|------|
| 种植费用 | **25～50** |
| `sunGain` / `stressGain` | 待定 |
| 进池 | 学校关；与压力机制关卡 synergize |

## 6. 协同示意

```text
[自动贩卖机 Main]  --25阳摇奖-->  随机食物 Consume 入手牌
                                      |
                                      v
[射手 Main + 文具盒 Support]  ------>  普攻 + 随机文具弹

[课本 Consume 种在 A 格 Main 上]  -->  玩家 +阳光
                                      右邻 B 格 Main +压力
```

| 组合 | 效果 |
|------|------|
| 贩卖机 → 食物 Consume | 经济循环：产阳 → 摇奖 → 再用食物 |
| 文具盒 + 高攻速 Main | 文具弹 DPS 放大 |
| 课本 + 章鱼噼 | 先课本给队友叠压 → 再章鱼噼清压换击杀（高阶玩法，需数值控） |
