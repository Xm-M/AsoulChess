## 功能描述
### 详细描述
羽川翼为压力体系植物（阳光 **150**）。

**常态（白羽川）**
- 行为对齐**普通向日葵**（`SkillEffect_CreateSunLight` + ColdSkill 产阳，数值对齐虹夏/向日葵）
- 入场挂压力 Buff，**无自加压**，仅吃外部加压
- 常态**关闭**近战普攻

**变身（黑羽川）** — 压力一到 **90 自动**进入（无需再点技能）
- 生命：`MaxHp += 变身时基础 MaxHp × 5`，当前 HP 同步增加同等数值
- 获得 **30%** 生命偷取（`Buff_BaseValueBuff_LifeSteal` 或等价）
- 变为近战：用可配 `IGridFindTarget` 大范围索敌，优先**距离自己最近**的敌人
- 移动：`MoveToTarget` 走到目标**邻格**后近战攻击；无目标则**原地待机**
- 可离开原种植格；**原格保持不可部署**（预订）
- 压力 **每秒 −2**（关卡时间）
- 外观：同 Prefab 切 Animator 状态 / Blend（黑形态）

**退回常态** — 压力归 **0**
- 移动回变身前所在格，恢复产阳、关掉近战、撤销 HP/吸血加成、切回常态动画
- 若原格因特殊原因无法回去 → **自身 Death**

### 用户故事
作为玩家，我希望种下羽川翼产阳，压力满时自动变黑猫近战清场，压力耗尽后再回原位产阳，以便融入压力构筑。

### 已确认决策
| 项 | 结论 |
|----|------|
| Q1 | 普通向日葵（单发阳光，对齐虹夏/向日葵） |
| Q2 | 压力 ≥90 **自动**变身 |
| Q3 | `MaxHp += 基础MaxHp×5`，当前血同步抬 |
| Q4 | `IGridFindTarget` 大范围 + 最近；无目标原地待机 |
| Q5 | 可离开原格；原格不可部署；邻格近战 |
| Q6 | 无法回原格 → **Death** |
| Q7 | 同 Prefab Animator 切换 |
| Q8 | 仅外部加压 |
| Q9 | 脚本 + Prefab/Asset 接线 |

### 集成点
- **调用**: `CreateSunLight`、压力 Buff、`MoveToTarget`、`IGridFindTarget`、近战 `CloseAttack`、`ChangeLifeSteeling` / 吸血 Buff、`Death`
- **触发**: 压力达 90 / 归 0；Timer 每秒降压；索敌循环
- **需注意**: 离格后原格 `stander` 预订；回格失败致死

### 对现有功能的影响
- **接口变更**: 尽量无全局 API；若预订需轻量 Tile 标记则局部扩展
- **行为变更**: 仅羽川翼；移动/占格需回归种植与铲除
- **数据变更**: Asset 填名/攻/速/CD；Prefab 挂产阳 ColdSkill、被动、近战武器、双形态动画

## 技术要求
- **依赖模块**: Skill, Buff, Chess, Move, Weapon, Map/Tile
- **性能**: 索敌 Timer 间隔可配（≥0.1s）；压力 Tick 1s
- **兼容性**: 向后兼容；不改全局产阳/压力协议
- **约束**: 无技能专用运行时 MonoBehaviour（`ISkillEffect` + Timer + 事件）
