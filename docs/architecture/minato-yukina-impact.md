## 影响评估
| 项 | 程度 | 说明 |

| 现有压力 Buff 类 | 无直接改动 | 仅调用 AddBuff/BuffReset |

| 性能 | 可忽略 | 每攻最多 4 格 |

## 回归测试建议
1. 友希那远程射击正常  
2. 上下左右各一友方：每次攻击各自压力 +1；首次即从 0→1  
3. 邻格敌方不加压；自身不挂压力  
4. 对角格友方不加压  
5. 邻格已是 MMK/Nina：压力仍增加、UI/阈值行为正常  
6. 铲除/离场后不再加压  
7. 边界格（地图边缘）不报错
