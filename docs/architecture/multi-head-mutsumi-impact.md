# 影响面分析: 多首的怪物

## 改动范围
| 项 | 类型 |
|----|------|
| 新被动 / Attack / Keys / **DiagonalThenLane** | 新增 |
| PropertyCreator + Prefab + 分身头 + 跨行子弹 Prefab | 新增资源 |
| `GameManage.allChess` / 商店（若需进池） | 配置 |
| Mortis / 黄瓜睦 / 压力全局 | **不改** |

## 影响评估
| 项 | 程度 | 说明 |
|----|------|------|
| 黄瓜睦 | 低 | 仅作为 basePlant 引用 |
| Mortis | 低 | 并列；种植互斥靠 LevelUp |
| 压力生态 | 低 | 只消费压力 |
| 性能 | 低 | 上限内额外弹道 |

## 回归测试
1. 黄瓜睦 → 多首 / → Mortis 两条线均可
2. 多首不能种在 Mortis 上
3. 压力 50/100 行为（+1 头 + 清零）
4. 1/2/多头时行序弹道；多头开火起点在各头；跨行先斜后直
5. 有头致死复活；无头真死
6. 铲除清理头
7. Mortis 原濒死逻辑未回归坏
