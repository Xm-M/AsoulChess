# 功能需求卡片: 图鉴系统 (CodexPanel)

## 基本信息
- 功能名称: 棋子图鉴面板
- 所属模块: UI系统
- 需求类型: 新增
- 优先级: P1
- 预估耗时: 2-3小时
- 提出日期: 2026-04-03

## 功能描述
实现棋子图鉴面板，让玩家查看自己拥有的棋子详细信息。面板分为左右两栏：
- **左栏**: 可按羁绊标签(plantTags)和定位类型(plantType)筛选，显示棋子图标+名称的选项卡列表
- **右栏**: 点击选项卡后展示棋子名称、图标、基础属性、羁绊标签、定位类型、描述（可滚动）
