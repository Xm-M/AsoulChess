# 功能需求卡片: 灯（高松灯升级 · 棋子模式）

## 基本信息
- **功能名称**: 灯（高松灯）
- **所属模块**: Chess / Skill / UI（PlantsShop）/ Map
- **需求类型**: 新增功能（新升级态单位 + 棋子部署机制）
- **优先级**: P1
- **预估复杂度**: L2（接近 A：升级种植 + 开技变商店卡 + 棋子上限 + 3×3 触发爆炸 + 邻格额外部署）
- **预估耗时**: 1.5～3 天（含棋子 Prefab / 商店槽切换）
- **提出日期**: 2026-07-24
- **参考**: [望 - PRTS](https://prts.wiki/w/%E6%9C%9B)（简化版，贴 MyGO）

## 功能描述
### 详细描述
新增植物「灯」：常服高松灯的**升级态**，必须种植在场上的高松灯上。常态仅普攻（继承灯射击）。当上下左右邻格存在 **4 名不同 MyGO 成员** 时可开启主动技能；开技后**一次性变身**为棋子模式：停止普攻，本关商店栏原「灯」卡变为「棋子」卡（需购买部署）。棋子种下即可触发；僵尸进入棋子 **3×3 爆炸范围** 时爆炸，对 3×3 内敌人造成伤害（灯攻击力 × 倍率，默认 **22.5**）。部署一枚棋子时，按灯邻格 MyGO 数量在邻格空位再部署等量额外棋子。场上棋子数量上限 = **全场 MyGO 成员数**。灯死亡时：清除场上全部棋子，并将商店栏棋子卡变回灯。

### 用户故事
作为玩家，我希望把高松灯升成「灯」，在凑齐邻格 MyGO 后开技，用可购买的棋子在路上埋雷清杂，体现乐队羁绊。

### 需求类型判定理由
全新升级态单位 + 棋子子单位 + 商店卡运行时切换；比望简化（无连线激活、无直线叠伤、无三技能），强化 MyGO 邻格/全场计数。

### 命名与身份（已确认）
| 字段 | 值 | 说明 |
|------|-----|------|
| 显示名 `chessName` | **灯（高松灯）** | 与常服区分 |
| `fetterMemberId` | **高松灯** | 与常服/企鹅/宇宙互斥计 1 Member |
| `plantTags` | **Mygo**（+ 建议主唱） | 羁绊 tag |

| `plantIfCanBuyCard` | `LevelUp_Limit`（+ 可选 OnlyOne） | 场上需有高松灯才可买 |
| 阳光 | **125**（灯）/ **25**（棋子） | 已确认 |

### 集成点
- **调用**: `LevelUpPlant.ifCanPlant`、MyGO 邻格/全场检测、`CreateChess`、爆炸 AOE、`PlantsShop` 槽位替换
- **触发**: 主动技开技；棋子碰撞/进格触发爆炸；灯 `OnRemove`/Death 清棋 + 还原商店卡
- **新接口**:
  - 灯主动技 + 棋子模式状态（停普攻、切商店卡）
  - 棋子单位（触发 3×3、伤害读灯 ATK×倍率）
  - 动态场上限（全场 MyGO 数）
  - 邻格额外部署逻辑

### 对现有功能的影响
- **接口**: 商店槽可能需「运行时替换 Creator」API（若尚无）
- **行为**: 不改常服高松灯；死亡清理棋子避免残留
- **数据**: 新增灯 / 棋子 Prefab + PropertyCreator

## 已确认规则

| 项 | 结论 |
|----|------|
| 开技范围 | 上下左右邻格；参考现有 MyGO 成员检测 |
| 开技条件 | 邻格 **4 名不同** MyGO；**不含灯自身**；重复成员只计 1（与现有 MyGO 设计一致，`fetterMemberId` 去重） |
| 开技后 | **一次性变身**；保持棋子模式至灯死亡 |
| 商店 | 仅本关商店那张灯卡变为棋子卡；购买部署棋子（价 25） |
| 棋触发 | 僵尸进入 **3×3 爆炸范围** 即触发 |
| 爆炸后 | **自身销毁**（土豆雷式，不可重复触发） |
| 爆炸伤害 | **灯攻击力 × 倍率**，默认倍率 **22.5**（可配）；只伤敌人 |
| 爆炸范围 | 3×3（棋子为中心） |
| 起身 | **无**；种下即可爆 |
| 额外部署 | 放主棋时，按灯**邻格** MyGO 数，在主棋**邻格空位**再放；**额外棋免费**；**每隔 `extraDeployInterval`（默认 0.1s）逐个种出** |
| 场上限 | **全场 MyGO 单位数**（**不去重**；有几株 MyGO 上限就是几） |
| 灯死亡 | **清除场上全部棋子** + **商店棋子卡变回灯** |
| 常态攻击 | 继承常服高松灯射击 |
| 动画 · 开技 | Animator **Blend → 1**（棋子形态；参考 Mutsumi `ChangeFloat`） |
| 动画 · 种棋 | **仅买卡种植**时灯播一次 attack；额外部署不播 |
| 范围 | **Chess 战斗单位**；与剧情/StoryMotion **无关** |

### 动画细则（已确认）
| 项 | 结论 |
|----|------|
| 开技瞬间 | `AnimatorController.ChangeFloat(1)`（或等价设 Blend=1），切到棋子形态动画层 |
| 种棋反馈 | **仅玩家买卡种植时**播一次 attack；邻格额外部署**不**触发灯 attack |
| 开技前 | Blend 保持常态（通常 0）；可正常普攻动画 |

### 已锁定细节（原建议项）
| 项 | 结论 |
|----|------|
| 开技计数是否含灯自己 | **不含**（邻格需 4 名其他不同 MyGO） |
| MyGO 去重 | `fetterMemberId`（无则 `chessName`；灯类 Contains「高松灯」归一）；重复只计 1 |
| 棋子爆炸后 | **销毁自身** |
| 额外部署费用 | **免费**（邻格 MyGO 触发的额外棋不扣阳光）；仅买卡种植扣 25 |
| 上限下降时已种棋子 | **不主动清除**；仅禁止再部署；灯死亡才清场 |
| 额外棋无空邻格 | 跳过无法放置的额外枚数 |
| 棋子占格 | **SupportPlant**（不写 `stander`，不挡主植物）；可叠种在已有 Main 上（南瓜罩同款）；同格不可再叠第二颗石头 |

## 技术要求
- **依赖**: Chess、Skill、Map/Tile、PlantsShop、Fetter/MyGO、ObjectPool
- **规范**: `ISkillEffect` / `ISkill`；禁止技能专用运行时 `AddComponent` MonoBehaviour
- **性能**: 棋子数量受 MyGO 人数限制（通常 ≤5～8），可接受
- **兼容**: 不改常服灯战斗逻辑；商店切换需回归无灯开局

## 功能清单
### 核心功能（必须）
- [ ] 灯 PropertyCreator + Prefab：`LevelUpPlant` 种在高松灯上；价 125；`fetterMemberId=高松灯`
- [ ] 常态：继承灯射击；主动技：邻格 4 不同 MyGO 可开
- [ ] 开技：停普攻；Blend→1；商店灯槽 → 棋子 Creator（价 25）
- [ ] 种棋：仅玩家买卡种植时灯 Play attack 一次（额外部署不播）
- [ ] 棋子：种下可触发；进 3×3 范围爆炸；伤 = 灯 ATK × 22.5（可配）
- [ ] 部署：邻格 MyGO 数 → 邻格空位额外部署（**免费**）；场上限 = 全场 MyGO 数
- [ ] 棋子爆炸后销毁；灯死亡：清全部棋子；商店槽还原为灯

### 扩展功能（可选）
- [ ] 棋子爆炸特效 / 音效
- [ ] 邻格 MyGO 不足 4 时 UI 提示
- [ ] 图鉴文案

## 验收标准
- [ ] 只能种在高松灯上；价 125
- [ ] 邻格未满 4 不同 MyGO 不可开技；满 4 可开，开后保持棋子模式
- [ ] 开技后 Blend=1；商店对应槽变为棋子（25）；可买可种；达全场 MyGO 上限后不可再种
- [ ] 仅买卡种植时灯播一次 attack；额外部署不触发
- [ ] 放棋时邻格每有 1 MyGO，尽量在邻空再放 1（**免费**；无空位或触上限则跳过）
- [ ] 僵尸进入棋子 3×3 范围触发爆炸；伤害 = 灯 ATK × 22.5；爆炸后棋子销毁；只伤敌人
- [ ] 灯死亡：场上棋子全清；商店槽变回灯
- [ ] 与剧情系统无关；常服灯未开技行为不变

## 风险评估
| 风险点 | 概率 | 影响 | 应对措施 |
|-------|------|------|---------|
| 商店槽运行时换卡无现成 API | 中 | 中 | 扩展 PlantsShop / Hand 槽替换；参考携带格显隐 |
| 灯 ATK 引用：灯已死 vs 棋子爆炸 | 低 | 高 | 爆炸前缓存灯 ATK，或棋子持有开技时快照 |
| MyGO 计数口径不一致 | 中 | 中 | 统一 `fetterMemberId` 去重；与 PassiveSkill_Mygo 对齐文档 |
| 额外部署占格失败 | 中 | 低 | 跳过；不扣上限外额度 |
