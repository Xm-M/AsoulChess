# 章鱼噼篇 v1.0 — 制作定稿修订说明

> 本文档对 `少女乐队 PVZ｜章鱼噼篇剧情文档 v1.0.md` 做**实现向定稿**，不替换原编剧分场；策划、美术、程序以本文 + 美术清单为准。

**修订日期**：2026-05-20

---

## 1. 敌人设定（纠正 v1.0 易误解点）

### 1.1 「旁观者」不是抽象路人

v1.0 中「旁观者」易被理解为「被广播变形的活人」。**定稿**：

- 战斗中出现的「往外涌、挡路」的单位 = **校园僵尸**，不是新种族的「情绪路人」。
- **旁观者**是校园僵尸的一种，与霸凌生态里其他身份并列。

### 1.2 校园僵尸五种（战斗直接复用 Prefab）

| 游戏内名称 | 霸凌身份隐喻 | 项目资源 |
|------------|--------------|----------|
| 旁观者 | 冷漠、随大流往外走 | `Prefab/ChessPrefab/Zombie/学校/旁观者/` |
| 毒舌妇 | 恶语、流言压力 | `.../毒舌妇/` |
| 霸凌者 | 主动冲撞、精英感 | `.../霸凌者/` |
| 包庇者 | 和稀泥、护场 | `.../包庇者/` |
| 攀附者 | **追随者**（文档用语 = 游戏内攀附者） | `.../攀附者/` |

**追随者 = 攀附者**（已定稿）。文档、关卡表、对白中写「追随者」时，程序与美术均指向 `攀附者`。

### 1.3 取消单独设计的敌人

v1.0 §10 中「流言旁观者」「沉默旁观者」等**不必新画**；用现有五种僵尸 + 关卡配表区分行为即可。例如：

| 文档概念 | 建议用僵尸 |
|----------|------------|
| 缓慢往出口走 | 旁观者 |
| 快、绕路、后门压力 | 毒舌妇、攀附者 |
| 冲撞 | 霸凌者 |
| 护场、减伤感 | 包庇者 |

### 1.4 老师 Boss

**息事宁人者**仍为单独 Boss（象征「别闹大」的压迫），小怪召唤用校园僵尸。Boss 本体需新美术，见美术清单。

### 1.5 叙事与玩法措辞

- **叙事**：广播事故后，全校陷入异常，僵尸群试图离开学校，须拦住以防扩散。
- **玩法**：PVZ 式防守，**不是**「击杀活人」；与现有学校关一致。
