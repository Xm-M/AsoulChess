# 进度跟踪器

## 目的

提供完善的进度跟踪能力：
1. 记录每个功能的开发状态和时间
2. 生成进度统计和可视化报告
3. 支持进度历史查询
4. 识别开发瓶颈

## 使用场景

**更新功能状态**：
```
@progress-tracker update
需求: [需求ID]
功能: [功能ID]
状态: [状态]
```

**查看进度统计**：
```
@progress-tracker stats
需求: [需求ID]
```

**生成进度报告**：
```
@progress-tracker report
需求: [需求ID]
格式: [markdown/json]
```

## 状态定义

| 状态 | 说明 | 可转换至 |
|------|------|----------|
| `not_started` | 未开始 | `in_progress` |
| `in_progress` | 进行中 | `completed`, `blocked`, `cancelled` |
| `completed` | 已完成 | - |
| `blocked` | 被阻塞 | `in_progress` |
| `cancelled` | 已取消 | - |

## 工作流程

### 更新功能状态

```
接收更新请求
    ↓
读取功能列表
    ↓
验证状态转换合法性
    ↓
更新功能状态
    ↓
记录时间戳
    ↓
添加备注（可选）
    ↓
保存进度文件
    ↓
生成更新确认
```

### 进度统计

```
读取功能列表
    ↓
统计各状态功能数
    ↓
计算完成百分比
    ↓
分析开发效率
    ↓
生成统计报告
```
