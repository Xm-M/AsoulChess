# Lifecycle Demo (P1-0)

1. Import **Lifecycle Demo** from Package Manager → AsoulChess Game Entity → Samples.
2. Create an empty scene with a GameObject + `LifecycleDemoRunner`.
3. Enter Play Mode — Console should log Init → OnEnterCombat → Tick.
4. Press **D** to Die (OnLeaveCombat + Death event).

No board, no combat controllers required.
