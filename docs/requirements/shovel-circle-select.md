# 功能需求卡片: 铲子圆圈检测与优先级铲除

## 基本信息
- **功能名称**: 铲子圆圈检测与优先级铲除
- **所属模块**: UI（手持物 / `ShovelPanel`）+ Chess / Map（`PlantType`）
- **需求类型**: 功能扩展
- **优先级**: P1
- **预估复杂度**: L1
- **预估耗时**: 2–4 小时
- **提出日期**: 2026-07-10

## 功能描述
### 详细描述
将铲子从单点射线命中即铲，改为以鼠标世界坐标为圆心的小圆检测；实时用文本显示当前将被铲除的植物名；多目标时按类型优先级选中；花盆类在存在其他植物时不可铲。

### 用户故事
作为玩家，我希望铲子能准确选中同格/邻近的目标植物并看到名称提示，以便优先铲掉辅助植物、且不会误铲仍承托其他植物的花盆。

## 现有业务上下文

### 相关现有功能
| 功能 | 模块 | 关系 | 说明 |
|------|------|------|------|
| `ShovelPanel` | UI | 被修改 | 当前 `Raycast` Layer7 → `Death()` |
| `PrePlantImage` | UI | 扩展 | 挂载名称文本；调度手持物协程 |
| `PlantType` / `Tile` | Map / Chess | 依赖 | Support / Main / Pot / Consume 分类 |
| `Chess.UnSelectable` | Chess | 约束 | 暂仍排除（不同 Layer） |
| `PlantsShop.DigPlant` / `ConveyorPanel.DigPlant` | UI | 入口不变 | 仍走 `HandItemType.Shovel` |

### 需求类型判定理由
在现有铲子手持物流上增强检测与选中规则，不新增独立系统。

### 集成点
- **调用的现有接口**: `Chess.Death()`、`PropertyCreator.chessName`、`PlantType`、`PrePlantImage` 显隐回调
- **触发的现有事件**: 铲除后仍走 `Death()` → `WhenDeath` 等既有链路
- **需要的新接口**: 铲子目标解析（可内聚在 `ShovelPanel` 或小 helper）

### 对现有功能的影响
- **接口变更**: 无对外 API 破坏；`DigPlant` 签名不变
- **行为变更**: 检测形状、多目标优先级、花盆保护、名称 HUD
- **数据变更**: 无存档变更；Prefab 增加文本子节点与可选半径字段

## 已确认规则

| 项 | 结论 |
|----|------|
| 检测 | `Physics2D.OverlapCircle`，半径默认 **1**，可调 |
| 名称 UI | 挂在 `PrePlantImage` 下，跟随鼠标 |
| 优先级 | `SupportPlant` > `MainPlant`；同优先级取**最近** |
| 花盆 | **仅当圆内没有其他可铲植物时**可铲 `PotPlant`；有其他植物时花盆不可选 |
| 消耗品 | `Consume` **不参与**铲除候选 |
| 左键 | 有合法目标 → 铲当前目标；无目标 → 取消 |
| 右键 | 取消（保持） |
| UnSelectable | **暂时排除**（圆检测仍用植物可选 Layer）；后续可改为也可铲 |

## 技术要求
- **Unity版本**: 项目当前版本
- **依赖模块**: UI、Chess、Map
- **性能要求**: 每帧一次小半径 OverlapCircle，候选通常 ≤ 数个
- **兼容性要求**: 向后兼容入口；行为对玩家可见变化
- **平台支持**: 现有 PC 输入

## 功能清单
### 核心功能（必须）
- [ ] 圆圈检测（半径可调，默认 1）
- [ ] 候选过滤：排除死亡、Consume、UnSelectable（当前 Layer）、花盆保护规则
- [ ] 优先级：Support > Main；同级最近
- [ ] `PrePlantImage` 下名称文本实时刷新；无目标时清空/隐藏
- [ ] 左键铲当前目标 / 无目标取消；右键取消

### 扩展功能（可选）
- [ ] Scene/Gizmo 画出检测圆（调试）
- [ ] 后续：UnSelectable 也可被铲（需扩 Layer 或改选中语义）

## 验收标准
- [ ] 单株主植物：圆内可铲，名称正确
- [ ] 主+辅助：优先铲辅助，名称显示辅助
- [ ] 多辅助：铲距离圆心最近者
- [ ] 花盆+其他：只能铲其他，不能铲花盆
- [ ] 仅花盆：可铲花盆
- [ ] 消耗品：不出现在候选/名称中
- [ ] 点空/无合法目标左键：取消并播 cancel
- [ ] 武装土豆雷等 UnSelectable：暂不可铲
- [ ] 入口 `PlantsShop` / `ConveyorPanel` 仍可用

## 风险评估
| 风险点 | 概率 | 影响 | 应对措施 |
|-------|------|------|---------|
| 半径 1 过大误扫邻格 | 中 | 中 | 半径可调；验收时调参 |
| Prefab 未挂文本引用 | 中 | 低 | 空引用时静默不显示名，不阻断铲除 |
| UnSelectable 与「按理可铲」预期不符 | 低 | 低 | 需求已约定暂排除，文档标注后续 |
