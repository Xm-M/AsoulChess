# 影响面分析: 灯（高松灯升级 · 棋子模式）

## 改动范围
- **类型**: 新增功能（新单位 + 新技能）+ 少量既有类型扩展（`IfCanBuyCard`）
- **主改模块**: Skill、Chess 配置、UI Shop（调用既有 API）

## 直接影响
| 影响项 | 文件/系统 | 原因 | 程度 |
|--------|-----------|------|------|
| 新主动/被动技能 | `Mygo_Skill` / `ISkillPassive/Mygo` | 棋子模式与爆炸 | 高（新增） |
| 商店槽换卡 | `ShopIcon.RefreshGood` / `PlantsShop.currentShopIcons` | 开技/死亡切换 Creator | 中 |
| 买卡上限 | `IfCanBuyCard` 新实现 | 动态 MyGO 上限 | 中 |
| 种植流程 | `WhenPlantChess` / `CreateChess` | 额外部署 + attack | 中 |
| 常服高松灯 | 仅作 `basePlant` | 升级目标 | 低 |

## 间接影响
| 影响项 | 验证 |
|--------|------|
| MyGO 羁绊 / `PassiveSkill_Mygo` 邻格计数 | 灯与常服同场、去重是否一致 |
| 宇宙高松灯 / LevelUp 互斥 | 升灯后常服移除；勿与宇宙冲突 |
| Fetter Mygo 改商店 CD | 换卡后仍按新 Creator 的 tag/价 |
| 阳光扣除 | 仅买卡主棋扣 25；额外免费 |

## 不修改（应保持）
- 常服高松灯射击逻辑
- 剧情 / StoryMotion
- `Item_PlantCard` 传送带（本需求走顶栏 `ShopIcon`）

## 风险
| 风险点 | 概率 | 影响 | 应对 |
|--------|------|------|------|
| RefreshGood 后 CD/灰态异常 | 中 | 中 | 换卡后测冷却与可点状态 |
| 额外棋连锁再部署 | 中 | 高 | 额外部署打标，禁止递归 |
| 灯死亡清棋漏网 | 低 | 高 | context 列表 + 全队扫 creator |
| 动态上限与 OnlyOne 叠加 | 低 | 中 | `MultyIfCanBuyCard_And` 测组合 |

## 回归测试建议
必须：
- [ ] 灯只能种在常服高松灯上；价 125
- [ ] 邻格 &lt;4 不同 MyGO（不含自身、去重）不可开技；=4 可开
- [ ] 开技后 Blend=1、停普攻、商店灯→棋子(25)
- [ ] 买卡种棋：扣 25、灯播 attack 一次；邻格 MyGO 数免费额外部署；无空位/达上限跳过
- [ ] 额外棋不播 attack、不扣阳光、不二次额外
- [ ] 敌人进棋子范围 → 3×3 伤（灯 ATK×22.5）→ 棋子销毁
- [ ] 达全场 MyGO 上限后不可再买棋
- [ ] 灯死亡：棋子全清；商店还原为灯
- [ ] 常服灯未升级行为不变；与剧情无关

建议：
- [ ] 铲除灯 / 灯被吃
- [ ] MyGO 中途减少后上限下降（已种棋保留、不能再买）
- [ ] 与压力希/天素罗等同场羁绊计数
