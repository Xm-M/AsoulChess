# 植物 × 乐队构筑 — 设计演进与模式分化

> **文档性质**：策划设计备忘（解决「冒险 vs 肉鸽 vs 羁绊 vs 槽位」的认知混乱）。  
> **最后更新**：2026-05-30  
> **关联**：[植物构筑设计指南](./plant-deckbuilding-design.md) · [肉鸽策划](../肉鸽.md) · [羁绊词条库](./band-instrument-bonds-reference.md)

---

## 1. 你遇到的不是「选 Plant 还是选 Prop」

表面上的混乱：

```text
乐队换皮 → 强羁绊 → 冒险没成长感 → 做肉鸽 → 槽位太少拿牌没正反馈 → 想全放遗物 → 又怕失去 plant 吸引力
```

**根因**：试图用 **同一套强度规则** 同时满足三个目标：

| 目标 | 需要什么 |
|------|----------|
| **IP / 乐队感** | 成员一起出场、有团感 |
| **冒险模式** | 线性扩工具箱、每关针对性变强 |
| **肉鸽模式** | 每选一次都有构筑正反馈（尖塔感） |

这三个目标 **可以共用同一批角色**，但 **不应该共用同一套羁绊强度模型**。

---

## 2. 设计演进时间线（记录）

### 阶段 A — 换皮 PVZ

- 波奇=坚果、虹夏=向日葵、凉=食人花、喜多=樱桃……
- **问题**：更强 plant 替换更弱 → 大量成员永不上场；同乐队很少一起带 → **没有「乐队」感**。

### 阶段 B — 强绑定羁绊

- 必须带齐整队成员才触发完整效果 → 保证每个乐队都被使用。
- **问题**：放进 **线性冒险** 后，一张图可能就凑齐一队 → 后续只剩「换乐队」而非「越来越强」；针对性 plant、补强 plant 的冒险节奏被破坏。

### 阶段 C — 肉鸽承载构筑

- 开局选乐队 → Run 内 plant 都是 **补强该体系**；三选一、商店、难度曲线。
- **问题**：PVZ **本关仅 ~10 槽**（`PlantsShop.maxCount`），Run 池子可以涨到 30+，但 **多数牌永远进不了本关手牌** → 拿牌正反馈远低于杀戮尖塔（拿到就能进卡组）。

### 阶段 D — 想把体系挪到遗物

- Prop/遗物不占 plant 槽，每次获得都能生效。
- **问题**：玩家最感兴趣的是 **「植物 / 成员」**，全放遗物会削弱 IP 与 plant 的关注度。

**结论**：不是二选一，而是 **按模式拆分「乐队感放哪、强度放哪、正反馈从哪来」**。

## 3. 推荐总框架：双模式 + 双维度（与现有文档对齐）

已在 [plant-deckbuilding-design.md §1](./plant-deckbuilding-design.md) 写过，这里用决策语言再定一遍：

```text
┌─────────────────────────────────────────────────────────────┐
│  角色（Plant）= 玩家情感与场面主体（占格、技能、立绘）        │
├─────────────────────────────────────────────────────────────┤
│  冒险模式：Plant = 线性解锁的「工具箱」                       │
│  肉鸽模式：Plant = Run 内「体系组件」+ 可选「槽位升级」       │
├─────────────────────────────────────────────────────────────┤
│  Prop / 羁绊 aura = 「拿到就生效」的规则层（不占 plant 槽）   │
└─────────────────────────────────────────────────────────────┘
```

### 3.1 冒险模式（主线）

| 维度 | 设计 |
|------|------|
| 解锁 | 线性获得 plant，越玩池子越大 |
| 乐队 / 羁绊 | **软羁绊**：2/3/5 人阶梯小加成；**不要求凑满才「能玩」** |
| 强度曲线 | 来自 **新 plant 类型**（针对、灰烬、前排）+ 关卡教学，不是 Run 构筑 |
| 乐队感 | 图鉴、剧情、可选「推荐编队」成就；不 force 整队 |

**原则**：冒险回答「我有哪些牌可以应对这一关」；不回答「我这 Run 的体系是什么」。

### 3.2 肉鸽模式（Run）

| 维度 | 设计 |
|------|------|
| 开局 | **选乐队 = 选职业**（5 张 starter 固定身份，类似 STS 角色初始牌） |
| Run 成长 | **三条并行轴**，避免「只有加 plant 池」一条道 |

```text
轴 1 — Plant 池（ownedPlantCreatorIds）
        → 扩大「下一场战斗可以选谁上场」

轴 2 — Prop / Run 被动（ownedPropIds + 乐队 aura）
        → 每次获得几乎必生效（尖塔遗物感）

轴 3 — 槽位内升级（休息房 / 三选一「升级已有成员」）
        → 不增加 body 数量，增强已在用的 5~10 张
```

| 乐队完整羁绊 | **仅肉鸽**、且建议改为：**5 人全在本关 loadout（10 槽）内 → 触发 aura**；不是「池子里有 5 人就行」 |
| 正反馈 | 见 §4 |

## 4. 解决「30 张牌只有 5 张有用」— 不必放弃 Plant

杀戮尖塔：**卡组 = 本局全部资源**。  
本作：**池子（仓库）≠ 本关手牌（10 槽）**。  
若奖励语义仍是「往牌库加一张」，必然失望。

### 4.1 改奖励语义（推荐 P0）

| 奖励类型 | 玩家感受 | 实现方向 |
|----------|----------|----------|
| **A. 角色升级** | 「我的虹夏变强了」 | 三选一提供 LevelUp 形态 / 数值 tier（已有 LevelUp plant） |
| **B. 职能替换** | 「换一张更好的灰烬」 | PlantPick 按 **七类定位** 发牌（见 plant-deckbuilding §4），同职能竞争 |
| **C. 战前装配** | 「新成员下关可以带进槽」 | 战斗前从池子 **选 10 张 loadout**（可选 P1 UI） |
| **D. Prop** | 「拿到立刻全局生效」 | 经济配置里提高 Prop 权重 |
| **E. 休息：删/换** | 「清掉占池子的弱 starter」 | 休息房二期（文档已预留） |

**关键句**：肉鸽里 **不是每张 plant 都要每关上场**；价值可以是 **(1) 本关 loadout 选项 (2) 升级路径 (3) 职能覆盖 (4) 乐队 aura 组件**。

### 4.2 乐队羁绊 — 从「硬门槛」改为「Loadout 条件」

| 旧思路（导致混乱） | 新思路（建议） |
|-------------------|----------------|
| 池子里集齐乐队才强 | **本关 10 槽里** 含乐队 5  starter → 触发 **乐队 Prop 级 aura** |
| 凑不齐 = 角色废 | 单成员仍有 **独立职能**；凑齐 = **额外** 30% 类加成 |
| 冒险也要凑队 | **冒险无 aura 或仅 2 人小加成** |

这样：

- **Plant 仍是关注中心**（你要把谁放进 10 槽）。
- **Prop 承载「凑齐团」的大效果**（aura 可以显示为「乐队共鸣」遗物，逻辑上绑 plant 成员）。
- **不必把数值全塞进 Prop 表** — aura 的 **触发条件** 绑 plant，**数值** 可写在 Fetter / Buff。

与 [plant-deckbuilding-design.md §7](./plant-deckbuilding-design.md) 一致：*少做「只有凑满才生效」的 hard gate* → 改为 **凑满 Run 内 loadout 才满档**。

### 4.3 开局 5 人 vs 后续补强

```text
开局 5 人 = 乐队 identity（1 前排 + 1 产 sun + 1 输出 + 1 过渡/灰烬 + 1 辅助）  ← 定模板
Run 内获得 ≈ 5 张「可替换槽位」+ 若干 Prop + 升级

整 Run 约 10 张「真正在构筑里竞争」的 body — 与 10 槽一致，设计目标对齐。
```

后续 PlantPick **优先**：升级已有 starter、同职能高 tier、针对本 Act 僵尸的 counter — **而不是** 无限制往池子丢第 31 张。

## 5. 三个常见误区（对照自检）

| 误区 | 澄清 |
|------|------|
| 「冒险也要强羁绊」 | 否。冒险 = 工具箱；羁绊做收集/轻度加成即可。 |
| 「肉鸽拿 plant 必须像尖塔每张都进卡组」 | 否。本作是 **池 + 槽**；要么改语义（升级/替换/loadout），要么加 Prop 轴。 |
| 「体系只能放 Plant 或只能放 Prop」 | 否。**Plant = 谁在场**；**Prop/aura = 规则与乘区**；**升级 = 同 slot 变强**。 |
| 「一个乐队一张图就集齐就没成长」 | 仅当「集齐 = 结束」时成立；应把成长放在 **升级 / Prop / 新 Act 压力 / loadout 选择**。 |

## 6. 待拍板的设计决策（请策划勾选）

### D1 — 冒险模式羁绊强度

- [ ] **A（推荐）** 软阶梯：2 人 / 3 人 / 5 人小加成，单卡永远可独立使用  
- [ ] **B** 冒险不做羁绊，仅图鉴展示  
- [ ] **C** 维持强绑定（不推荐，与冒险节奏冲突）

### D2 — 肉鸽乐队完整效果触发条件

- [ ] **A（推荐）** 本关 10 槽 loadout 含乐队 5 starter → 满档 aura  
- [ ] **B** Run 池拥有 5 人即触发（易与槽位脱节）  
- [ ] **C** 纯 Prop 遗物触发，与 plant 无关（IP 弱）

### D3 — PlantPick 主要发什么

- [ ] **A（推荐）** 职能替换 + 升级为主，纯新增 body 控制在 ~5 张/Run  
- [ ] **B** 继续大量新增 body（需接受多数不上场）  
- [ ] **C** 几乎不发 plant，主要发 Prop（极端）

### D4 — 战前 loadout UI

- [ ] **A** 每战前从池选 10 张（正反馈清晰，要 UI）  
- [ ] **B** 自动：最近使用的 10 张 + 新卡优先提示  
- [ ] **C** 维持现逻辑：池子全可选进 shop（易超载）

## 9. 一句话总结

> **Plant 永远是主角；Prop/aura 负责「拿到就爽」；冒险管「池子越来越大」，肉鸽管「10 槽越来越精」。**  
> 乐队团感放在 **肉鸽 loadout + aura**，不要绑架冒险线性成长，也不要指望「无限加 plant 池」 alone 产生尖塔式正反馈。
