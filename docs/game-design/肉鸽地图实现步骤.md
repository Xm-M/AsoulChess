# 肉鸽地图实现步骤（与当前仓库对齐）

**状态**：核心数据与生成器已落在 `Assets/Script/Roguelike/Map/`；**地图 UI、存档、主菜单入口** 仍需你按下面步骤接好。

---

## 1. 和现有系统的关系

| 已有 | 肉鸽新增 |
|------|----------|
| `LevelData`：单关波次、场景、`outcome` | 不替代；战斗格从池子里**抽**一条 `LevelData` |
| `LevelManage.ChangeLevel` | 点战斗节点 → `RoguelikeRunService.EnterCombatNode()` |
| `LevelData.nextLevel` 线性链 | **不用**表达分叉；用 DAG + `RoguelikeRunState` |
| `StartUI` 选关卡片 | 另加「开始肉鸽」按钮 |

配置链：

```text
RunMapConfig（1 个）
  → ActMapConfig × 3（每幕地图参数 + 关卡池）
    → LevelData（多条，按 1 旗/2 旗/Boss 分池配置）
```

## 3. 你要做的配置（Unity 编辑器）

### 3.1 创建资源

1. **Project** 右键 → `Create → Roguelike → Act Map Config`（做 3 份：Act1/2/3）。
2. 右键 → `Create → Roguelike → Run Map Config`（1 份，拖入三个 Act）。
3. 建议目录：`Assets/Config/Roguelike/`（可自行建文件夹）。

### 3.2 填 ActMapConfig（对照 `肉鸽.md` §4.2）

- **拓扑**：`layerCount`（如 Act1≈12）、`min/maxWidthPerLayer`（3～4）。
- **配额**：`normalCombatCount`、`eliteCombatCount`、`restCount`、`shopCount`、`eventCount`。
- **Boss**：`bossLevel` 拖一条 Boss 用 `LevelData`。
- **关卡池**：`normalLevelPool` / `eliteLevelPool` 拖入对应难度的关卡资产（可用 `Resources/LevelData/AdvanceMode` 里现成的，或复制专用于肉鸽的）。

### 3.3 RoguelikeMapPanel 外观配置（Inspector）

打开 `Resources/UIPrefab/RoguelikeMapPanel`：

| 分组 | 字段 | 说明 |
|------|------|------|
| 层级引用 | `panelBackground` | 全屏背景 Image + Sprite |
| | `mapBackgroundImage` | 地图区域内底图（卷轴/山等） |
| | `mapViewport` / `linesRoot` / `nodesRoot` | 建议自建层级并拖引用，**关掉 Auto Generate Missing Ui** |
| 布局 | `layerSpacingY` / `slotSpacingX` | 节点间距 |
| | `mapOffset` / `mapScale` | 整图平移、缩放 |
| | `nodeSize` | 节点 Rect 大小（用预制体时也生效） |
| 节点 | `nodePrefab` | 带 `RoguelikeMapNodeWidget` 的预制体（推荐） |
| | `nodeTypeStyles` | 各房间类型 Sprite / 颜色 / 文字 |
| | `nodeStateStyle` | 锁定/可选/当前/已通关 等状态色 |
| 连线 | `lineStyle` | 粗细、颜色、Sprite |
| | `linePrefab` | 可选连线预制体 |
| 视觉资产 | `visualSettingsAsset` | 可选 SO，覆盖节点/连线样式 |

也可 `Create → Roguelike → Map Visual Settings` 做主题资产。

### 3.4 肉鸽战斗关的 LevelData

- 每条进池的 `LevelData` 的 **`outcome`** 设为 **`LevelOutCome_Roguelike`**（SerializeReference）。
- **不要**依赖 `nextLevel` 自动进下一关。

## 4. 实现顺序（推荐）

### 阶段 A — 验证生成器（无 UI）

1. 临时写个 Editor 菜单或测试按钮：`MapGenerator.Generate(actConfig, 12345)`，在 Console 打印每层节点类型。
2. 确认 Act1 能稳定生成、精英数量与 Boss 前休息符合预期。

### 阶段 B — 地图 UI（`MapView`）

1. 新建 `RoguelikeMapPanel : View`，注册进 `UIRoot`（与 `StartUI` 相同方式）。
2. 根据 `RoguelikeRunService.State.currentMap`：
   - 按 `layer` / `slot` 布局节点按钮；
   - 画线（`UILineRenderer` / 多个 Image / 预制 Line）。
3. **可点击**：仅 `State.GetSelectableNextNodes()` 里的节点 `interactable = true`。
4. 点击 → `RoguelikeRunService.TrySelectNextNode(id)`：
   - 战斗类 → `RoguelikeRunService.EnterCombatNode()`；
   - 商店/休息/事件 → 先弹占位面板（或复用 `CoinShopPanel`），`OnNodeResolved` 后刷新地图。

### 阶段 C — 主菜单入口

在 `StartUI` 增加按钮：

```csharp
RoguelikeRunService.StartNewRun(yourRunMapConfig);
UIManage.GetView<RoguelikeMapPanel>()?.Show();
```

### 阶段 D — 战斗返回地图

1. 肉鸽池内 `LevelData` 使用 `LevelOutCome_Roguelike`。
2. 胜利后：`LevelOutCome_Roguelike` 已调用 `OnCombatFinished(true)`。
3. 在 `RoguelikeRunService.OnNodeResolved` 或 MapView 里：
   - `SceneManage` 回到「地图场景」或仅 `Show` 地图面板；
   - 若仍在战斗 additive 场景，需 `LoadScene` 回开始/地图场景（与你们 `SceneManage` 策略统一）。

### 阶段 E — 存档（可选，后做）

- 扩展 `GameSaveData` 或单独 `RoguelikeRunSaveData`，序列化 `RoguelikeRunState`。
- **不要**与按 `levelName` 的单关存档混用同一 key。

## 5. 运行时 API 速查

```csharp
// 开局
RoguelikeRunService.StartNewRun(runMapConfig, seed: null);

// 玩家点下一格
RoguelikeRunService.TrySelectNextNode(nodeId);

// 战斗节点：选路成功后
RoguelikeRunService.EnterCombatNode();  // 内部 LevelManage.ChangeLevel

// 战斗结束（Outcome 已接）
RoguelikeRunService.OnCombatFinished(win);

// 可选下一格
var next = RoguelikeRunService.State.GetSelectableNextNodes();
```

## 6. 与策划文档的差异说明

- 原 `肉鸽.md` 写的路径 `Assets/Scripts/Roguelike/` **不存在**；以 **`Assets/Script/Roguelike/Map/`** 为准。
- 「旗帜数」未加新字段：用**不同 `LevelData` 资产**表示 1/2/3/4 旗难度即可。
- 商店/休息/事件目前是**立即 MarkCleared**，后续再接真实玩法面板。
