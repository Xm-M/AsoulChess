# 乐队 × 乐器：羁绊设计参考清单

> **用途**：本游戏以乐队为核心，**乐器 ≈ 职业/定位**，**乐队/流派 ≈ 种族/阵营**。  
> 文档目标：在「鼓、贝斯、吉他、键盘、主唱」之外，扩充**可做成羁绊标签**的乐器与**典型乐队编制**，便于你挑子集进正式设定。

---

## 1. 设计用法（建议）

| 维度 | 游戏里可映射为 | 文档中对应 |
|------|------------------|------------|
| 乐器 | 职业、技能树分支、装备类型、攻击距离/节奏类型 | 第 2 节「乐器库」 |
| 乐队/流派 | 种族、阵营、羁绊套装名、地图/关卡主题 | 第 3 节「乐队模板」 |
| 羁绊规则示例 | 同队满足「乐队 A + 乐器 X」触发；或「任意国风乐器 ≥2」触发 | 第 4 节「组合提示」 |

**去重建议**：同一角色可挂 1 个「主乐器」+ 0～1 个「副乐器/编曲标签」，避免羁绊组合爆炸。

---

## 4. 羁绊组合提示（可直接改成表格数据）

### 4.1 按「乐器标签数量」解锁（简单）

- **铜管羁绊**：队伍中包含 `trumpet` + `trombone`（或 `horn_section`）  
- **弦乐羁绊**：`violin` + `cello`  
- **国风羁绊**：任意 2 个来自第 2.8 节  
- **拉丁节奏**：`congas` + `bongos` 或 + `timbales`  
- **不插电**：仅 `acoustic_guitar` + `cajon` + `主唱`（无电吉他等，可按你规则放宽）

### 4.2 按「乐队种族 + 主乐器」叠加（你描述的模型）

示例：

| 种族（乐队类型） | 建议「主职业乐器」池（抽 3～5 个做角色） |
|------------------|----------------------------------------|
| 放克大乐队 | 电贝斯、鼓、萨克斯、小号、电钢琴 |
| 斯卡团 | 吉他、贝斯、鼓、小号、长号 |
| 国风跨界 | 二胡、琵琶、古筝、笛子、中国打击 |
| 交响金属 | 主音吉他、键盘、小提琴、主唱 |
| 爵士小馆 | 钢琴、低音提琴、鼓、萨克斯 |

### 4.3 主唱是否算「乐器」

- **算**：羁绊条目多，易做「人声队」「阿卡贝拉」线。  
- **不算**：主唱单独做「无乐器职业」，乐器羁绊只数器乐——数值更好控。

文档里已把 `vocal_lead` / `vocal_harmony` 单列，你可二选一。

## 5. 最小落地建议（防组合爆炸）

1. **第一期**：摇滚四大件 + 主唱 + **6～10 个扩展乐器**（建议：萨克斯、小号、小提琴、二胡、古筝、琵琶、笛子、合成器主音、口琴、中国打击）。  
2. **乐队种族**：先做 **8～12 个**流派模板（第 3 节各取 1 个代表）。  
3. **每个角色**：`primary_instrument` + 可选 `secondary_tag`（如 `horn_section` / `strings`）。  
4. **抽象标签**：`horn_section`、`strings`、`chinese_wind` 等用于「少角色多羁绊」。
