# 需求开发审批报告：章鱼噼（消耗品）

## 基本信息
- **需求名称**: 章鱼噼 — 压力换击杀（保底）+ 解 Buff + Boss 免疫
- **需求 ID**: OCT-TAKOPI-001
- **所属模块**: Skill（Consume 植物）/ 章鱼噼篇
- **分析日期**: 2026-05-20
- **审批日期**: 2026-05-20
- **修订日期**: 2026-05-20

## 需求摘要
可种植消耗品 **「章鱼噼」**：种在己方植物上；按 `max(1, floor(压力/5))` 消灭僵尸（**霸凌者优先**）；**无压力 / 读不到 stress 也保底 1 只**；**Boss 级僵尸不可被选为目标**；并清除宿主 **压力** 与 **霸凌目标** Buff。剧情赠送获得。

**需求类型**: 新增功能

## 用户定稿记录

### 初稿（2026-05-20）
| 项 | 决定 |
|----|------|
| 种植 | `ConsumePlant`，仅种己方植物格 |
| 击杀 | `floor(压力/5)`，霸凌者优先 |
| 清 Buff | 清除 `压力` + `霸凌目标` |
| 获得 | 剧情赠送 |
| 名称 | 章鱼噼 |

### 修订（2026-05-20）
| 项 | 决定 |
|----|------|
| **保底击杀** | `击杀数 = max(1, floor(stress/5))`；`TryGet("stress")` 失败或无压力 Buff 视为 `stress=0`，仍保底 **1** 次击杀尝试 |
| **Boss 免疫** | `plantTags` 含 **`"Boss"`** 的敌方不可被选为目标（唯一判定，公共规则复用） |

### 终审（2026-05-20）
| 项 | 决定 |
|----|------|
| **Boss 识别** | 仅判断 `PropertyCreator.plantTags` 是否包含 `Boss` |
| **审批** | **通过**，进入开发 |
