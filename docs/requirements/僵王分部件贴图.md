# 功能需求卡片: 僵王分部件 Sprite 与血量/吐球高光

## 基本信息
- **功能名称**: 僵王脚/头/下巴三档破损贴图 + 吐球火冰眼嘴高光
- **所属模块**: Chess（`AnimatorController_Zombieking`）+ Skill（`Skill_ZombieKingBoss.RefreshPresentation`）
- **需求类型**: 功能扩展（对齐 `僵王.md` 与既有 `VisualTier` / `BallVisual`）
- **优先级**: P1
- **提出日期**: 2026-03-30

## 功能描述
- **血量档**（与 `僵王.md` 一致）：>80% 完整；50~80%、10~50% 脚/头/下巴切破损精灵；<10% 无第四套精灵，沿用第三档；全身闪烁仍由技能侧协程处理。
- **眼/嘴高光**：idle / 火 / 冰各一张 Sprite，**均与血量无关**；仅在处于 `SkillState` 且 context 为 `FireIceBall` 时用火或冰（`BallVisual` 0/1）。离场判定同上，避免高光卡住。
- **Prefab**：在 `AnimatorController_Zombieking` 上拖拽子物体 `SpriteRenderer` 与多组 `Sprite`；未配置则跳过对应部位。

## 验收标准
- [ ] Inspector 可配置六路 Renderer 与 `ZombieKingTiered3Sprites` 各组
- [ ] 血量跨档时脚/头/巴贴图切换正确
- [ ] 吐火/吐冰技能播放期间眼嘴高光正确，回 Idle 后恢复 idle 组

## 实现备注（代码锚点）
- `ZombieKingTiered3Sprites`、`AnimatorController_Zombieking.SyncPartSpritesFromContext`
- `Skill_ZombieKingBoss.RefreshPresentation` 内对 `AnimatorController_Zombieking` 的调用
