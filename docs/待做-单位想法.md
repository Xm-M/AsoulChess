## 1. 羽川翼

- **阳光**：150  
- **常态**：大向日葵（产阳逻辑对齐现有大向日葵）  
- **形态切换**：压力值增长到**阈值**时 → **黑猫形态**  
- **黑猫形态**：
  - 行为类似「猫猫」（移动 + 攻击场上随机僵尸）
  - **持续消耗压力**
  - 压力归 **0** → 变回常态  
- **待澄清**：压力阈值数值；黑猫移速/伤害；压力消耗速率；是否自带压力 Buff / 依赖外部加压
