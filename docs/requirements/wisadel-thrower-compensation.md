# 功能需求卡片: 维什戴尔投掷手补偿 + 爆裂攻倍率

## 基本信息
- **功能名称**: 维什戴尔被动/爆裂数值调整
- **所属模块**: Skill / Buff
- **需求类型**: 功能优化
- **优先级**: P1
- **提出日期**: 2026-07-03

## 变更说明

### 背景
原版方舟维什戴尔为投掷手：单次攻击含子弹直击 + 余震第二段。标记在第二段前已存在，好礼（标记增伤/爆炸）每发普攻都能参与。

本项目未单独实现投掷手职业，子弹仅一段直击；若标记在被动链末尾才挂上，首段余震/爆炸无法吃到本发标记。

### 改动 1：标记时机前移
**单次 Bullet 命中处理顺序**（调整后）：

```
1. 对 main 挂/刷新 WisadelMark
2. 好礼增伤（15% ATK，若已有标记 → 本发必触发）
3. 余震（50% ATK，九宫格）
4. 好礼爆炸（150% ATK，圆范围，15%/爆裂 100%）
5. 扣爆裂弹药
```

### 改动 2：爆裂 attackRate +10
- `Buff_WisadelBurst.attackRateBonus` 默认及 Prefab：**10**（`attackRate` 从 1 → 11）
- 与 `ChangeAttack` 语义一致，非固定 +10 攻击力

## 验收标准
- [ ] 首发子弹打未标记敌人也能触发标记增伤与爆炸判定
- [ ] 爆裂期间 ATK = 基础攻击 × 11（180 → 1980，未计其他 Buff）
- [ ] 余震/爆炸仍为 AOE 元素，不递归触发 Bullet 被动
