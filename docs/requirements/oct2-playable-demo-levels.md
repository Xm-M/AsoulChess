# 功能需求卡片: 10.2 可玩 Demo 内容包

## 基本信息
- **功能名称**: 10.2 可玩 Demo 内容包
- **所属模块**: LevelSystem / Roguelike / Dialogue / Chess / Skill / Prop / UI
- **需求类型**: 功能扩展（关卡链 + 肉鸽内容 + 单位内容）
- **优先级**: P0（里程碑）
- **预估复杂度**: A 级
- **预估耗时**: 约 6 周内容制作 + 1 周打磨出包（2026-08-13 → 2026-10-02）
- **提出日期**: 2026-08-13
- **目标上线**: 约 2026-10-02
- **修订**: 2026-08-13 — 「？」改为尖塔图文选项；道具目标 50；植物目标 100；僵尸盘点；未点名册按目标数锁定；首页/按钮换皮；肉鸽卷轴图 + 事件插画

## 功能描述

### 详细描述

为 10.2 可玩 Demo 补齐 **四种模式关卡**、**肉鸽构筑内容**（事件 / 道具 / 植物 / 僵尸）与 **外壳插画**（首页/按钮换皮、肉鸽卷轴底图、事件插画）。

四种模式目标（已确认）：

| 模式 | Demo 目标 |
|------|-----------|
| **小游戏** | 约 **20** 关可玩（现有 16，再补 4） |
| **剧情 / 冒险** | **草坪** 与 **学校 / 章鱼噼篇** 关卡+剧情跑通；迷雾=Ring、剧院**不进主线剧情** |
| **肉鸽** | 三幕地图（前院 / 学校 / 迷雾 Ring）+ **≥3 Boss**；「？」事件可玩；道具可获取；植物/僵尸池无占位单位 |
| **生存** | **同一前院**三档：普通（5 轮）/ 困难（10 轮）/ 无尽 |

迷雾与剧院：**冒险剧情以后再做**。迷雾用现有 Ring 关整理为可玩池；剧院 **后续做 10 关**战斗（无对白、不进冒险主线；完成度够再进肉鸽）。

### 用户故事

- 作为玩家，我希望四种模式都能打完明确闭环。
- 作为玩家，我希望冒险能从草坪打到学校章鱼噼篇结局。
- 作为玩家，我希望肉鸽能打完三幕、遇到「？」事件、拿到道具、用完整植物池构筑。
- 作为玩家，我希望打开游戏先看到新的首页和按钮，而不是占位壳。
- 作为玩家，我希望肉鸽地图是画好的卷轴，点「？」能看到事件插画。

### 需求类型判定理由

系统骨架已存在。本需求是 **内容补齐 + 少量接线**：关卡链、三幕绑定、事件池、道具效果、单位 Prefab/SO。不改战斗内核，不迁 Entity UPM。

### 集成点

- **调用的现有接口**:
  - `LevelManage.ChangeLevel`；`StartUI` 续关
  - `RunMapConfig` / `ActMapConfig`（关卡池、`bossLevel`、`eventStoryPool`）
  - `RoguelikeEventFlow` + `LevelOutCome_RoguelikeEventStory`
  - `PropEffect.Apply/Remove`、`RoguelikeRunPropPool`、奖励/商店 Item 流
  - `EnterMapPlugin_EndlessSpawnConfig`
  - `LevelController_Boss`
- **触发的现有事件**: `GameStart` / `GameOver`；通关 `completedLevelIds`；肉鸽节点 resolved
- **需要的新接口**:
  - `RoguelikeEventChoicePanel` + `RoguelikeEventChoiceData`（图、正文、2～3 选项、奖励/代价）
  - `PropEffect_*` **参数化**（同一脚本、多 SO 填不同数值/稀有度），避免 50 个类
  - 老师 Boss / Ring Boss 的 `ISkill`

### 对现有功能的影响

- **接口变更**: 战斗 API 原则上不动；Prop 用现有抽象类扩展。
- **行为变更**: 冒险世界顺序 **草坪 → 学校**；肉鸽三幕分场景；「？」不再掉进空池/误进战斗；道具可从事件/奖励/商店进入 Run。
- **数据变更**: LevelData、Dialogue、PropItemData、PropertyCreator、ActMapConfig.eventStoryPool、Economy 道具池、UI Sprite（首页/按钮/卷轴/事件图）。

## 技术要求
- **Unity版本**: 2022.3.15f1c1
- **依赖模块**: LevelSystem、Map、Roguelike、Dialogue/Story、Prop、Chess、Skill、UI、SaveSystem
- **性能要求**: 单关与现有前院/学校关同级；新 Prop 不在 `Update` 里全图扫描
- **兼容性要求**: 肉鸽存档键兼容；冒险 `levelName` 重排可清档
